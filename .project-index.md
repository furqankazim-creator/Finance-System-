### Backend (`/backend/`)

**Configuration Files:**
- `package.json` — Dependencies: Express, Mongoose, TypeScript, Supabase
- `tsconfig.json` — TypeScript configuration
- `.env.example` — Environment template
- `dist/` — Compiled output (after `npm run build`)

**Core Server** (`/src/`):
- `server.ts` — Express app entry point, middleware setup, route mounting

**Configuration** (`/src/config/`):
- `database.ts` — MongoDB connection with error handling

**Data Models** (`/src/models/`):
- `Organization.ts` — Tenant model
- `Client.ts` — Customer/vendor model
- `Project.ts` — Project with budget tracking
- `ExpenseCategory.ts` — Spending categories (fixed, variable, COGS, OpEx, revenue)
- `Expense.ts` — Expense records (vendor, category, amount, date)
- `Invoice.ts` — Invoice records (issued to clients)
- `InvoicePayment.ts` — Payments received against invoices
- `BankAccount.ts` — (Phase 2+) Bank account records
- `BankTransaction.ts` — (Phase 2+) Bank statement transactions
- `Payroll.ts` — (Phase 2+) Employee salary records
- `Budget.ts` — (Phase 2+) Budget planning
- `AiInsight.ts` — (Phase 2+) AI-generated insights
- `index.ts` — Models export file

**Business Logic** (`/src/controllers/`):
- `organizationController.ts` — Org CRUD (create, read, update)
- `clientController.ts` — Client CRUD with pagination & search
- `projectController.ts` — Project CRUD with budget tracking
- `categoryController.ts` — Category CRUD (filter by type)
- `expenseController.ts` — Expense CRUD with date range filtering
- `invoiceController.ts` — Invoice CRUD + payment recording + auto-overdue detection
- `dashboardController.ts` — Aggregated stats (revenue, expenses, top categories, outstanding invoices)
- `reportController.ts` — P&L report with monthly comparison

**API Routes** (`/src/routes/`):
- `organizations.ts` → `GET/POST/PUT /organizations`
- `clients.ts` → `GET/POST/PUT/DELETE /clients`
- `projects.ts` → `GET/POST/PUT/DELETE /projects`
- `categories.ts` → `GET/POST/PUT/DELETE /categories`
- `expenses.ts` → `GET/POST/PUT/DELETE /expenses`
- `invoices.ts` → `GET/POST/PUT/DELETE /invoices` + payment endpoints
- `dashboard.ts` → `GET /dashboard`
- `reports.ts` → `GET /reports/pl`
- `bankAccounts.ts` — Placeholder (Phase 2+)

**Middleware** (`/src/middleware/`):
- `auth.ts` — Supabase JWT verification
- `errorHandler.ts` — Error handling with proper HTTP status codes
- `validate.ts` — Request validation using express-validator

**Utilities** (`/src/utils/`):
- `money.ts` — Currency helpers (toCents, toDollars, formatCurrency, safeParseCents)
- `response.ts` — API response formatting (sendSuccess, sendError, buildPagination)

**Scripts** (`/src/scripts/`):
- `seed.ts` — Populates database with demo data (3 clients, 5 projects, 30 expenses, 10 invoices)

## 🚀 Quick Start

### Option 1: Automated Setup
```bash
bash QUICKSTART.sh
```

### Option 2: Manual Setup

**Backend:**
```bash
cd backend
cp .env.example .env          # Edit with credentials
npm install
npm run seed                  # Seed demo data (optional)
npm run dev                   # Runs on :5000
```

**Frontend** (new terminal):
```bash
cd frontend
cp .env.local.example .env.local  # Edit with credentials
npm install
npm run dev                   # Runs on :3000
```

**Open:** http://localhost:3000

## 📊 Database Schema

### Core Collections
1. **organizations** — Tenant/company
2. **users** — (via Supabase, not in MongoDB)
3. **clients** — Customers/vendors
4. **projects** — Work for clients
5. **expenses** — Money spent
6. **invoices** — Money to collect
7. **expense_categories** — Spending classification
8. **invoice_payments** — Payments received
9. **bank_accounts** — (Phase 2+)
10. **bank_transactions** — (Phase 2+)
11. **payroll** — (Phase 2+)
12. **budgets** — (Phase 2+)
13. **ai_insights** — (Phase 2+)

### Money Handling
- **All amounts stored as integers (cents)**
- Example: $19.99 = 1999 cents
- Conversion functions: `toCents()`, `toDollars()`, `formatCurrency()`

## 🔌 API Endpoints Summary

**Base URL:** `http://localhost:5000/api/v1`  
**Auth:** `Authorization: Bearer <jwt_token>`

```
GET    /organizations/me              — Get my org
POST   /organizations                 — Create org

GET    /clients                       — List clients (paginated)
POST   /clients                       — Create client
GET    /clients/:id                   — Get client details
PUT    /clients/:id                   — Update client
DELETE /clients/:id                   — Delete client

GET    /projects                      — List projects
POST   /projects                      — Create project

GET    /categories                    — List categories
POST   /categories                    — Create category

GET    /expenses?from=...&to=...      — List expenses (date range)
POST   /expenses                      — Record expense

GET    /invoices?status=sent          — List invoices
POST   /invoices                      — Create invoice
POST   /invoices/:id/payments         — Record payment

GET    /dashboard                     — Current month metrics
GET    /reports/pl?from=...&to=...    — P&L report
```
